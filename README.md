# sieucapvipro
**My website aims to help children visualize different physics problems so that they will understand more about those problems.**

My website consist of 5 different images. Each image will lead you to a physics problem when it is clicked.

Problem 1:
There is a cannon on the bottom-left corner of the map. You have to type in the angle of the cannon, press enter on your keyboard then type in the velocity of the bullet fired by the cannon.

Problem 2:
First you have to choose which liquid is in the glass at the middle of the screen. Then you have to type in your object's mass and volume so that the website will calculate if the object will float or not. Then you can change your object's state by clicking 2 buttons below the question: "Do you want to automatically
change your object state in the liquid?". Then you will have to type 1 or 2 into the prompt depending on which properties of the object do you want to keep mass or volume. After that the website will calculate and change the remaining properties, which you don't want to keep, in order to make your object change its state.

Problem 3:
First you have to choose one of the three icon at the right of the website. The clock icon means that you can only manually change the volume and temperature of the air inside the box. The temperature icon means that you can only manually change the volume and pressure, the box icon means that you can only manually change the pressure and temperature. Those properties of the air that you can't manually change the website will change for you.

Problem 4:
First you have to type in your object's angular speed(remember to press Enter). Then choose your object's starting point by dragging the slider at the bottom of the website. Press start when you are ready. 

Problem 5:
You can change the wave's properties by dragging the slider below

**WARNING:**
You should have basic knowledge about those physics problems before exploring them. You can search these physics problems online:

Problem 1: Oblique projectile motion

Problem 2: Buoyant force

Problem 3: Ideal gas law(Ideal gas equation)

Problem 4: Oscillation of a spring

Problem 5: Wave
